02Services

Briefly provides custom website design and development services. All websites are built from scratch — we do not use templates, page builders, or no-code tools such as Webflow, Framer, or Squarespace.

2.1 Core service

The core deliverable is a custom-designed, custom-built HTML landing page. Unless otherwise agreed in writing, each project includes:

  • A single landing page, custom designed and built
  • Responsive layout (desktop, tablet, and mobile)
  • WCAG AA accessibility compliance
  • Basic on-page SEO (meta tags, semantic structure, Open Graph)
  • Performance optimization for Core Web Vitals
  • One round of revisions (see Section 6)
  • Delivery as a clean, ready-to-publish HTML file

2.2 What is not included

Unless explicitly purchased as an add-on, the following are outside the scope of the core service:

  • Additional pages beyond the landing page
  • Domain registration or DNS configuration
  • Hosting setup or server configuration
  • CMS, back-office, or dynamic web application functionality
  • Ongoing maintenance, updates, or technical support
  • Copywriting or content creation
  • Photography, illustration, or third-party asset licensing

06Revisions

6.1 What is included

Each project includes one round of revisions. A "round" means a single set of consolidated feedback, submitted by email in one message, to which we respond with an updated deliverable. Revisions covered in the included round are limited to:

  • Adjustments to layout, spacing, or visual hierarchy
  • Copy edits or text changes
  • Color or typography adjustments
  • Minor content additions or removals consistent with the original brief

6.2 What is not a revision

The following are considered out of scope for the included revision round:

  • Changes that significantly alter the brief, concept, or structure
  • Addition of new sections or pages
  • Changes to functionality not originally requested
  • Revisions requested after the project has been marked as complete

Requests outside this scope will be quoted separately.

6.3 Revision deadline

Revision requests must be submitted within 7 calendar days of receiving the first draft. After this period, the project is considered complete and the revision entitlement lapses.

6.4 Additional revisions

Additional revision rounds may be purchased at €79 per round. Additional rounds must be requested and paid for before work begins on the revision.
